## 1. Сутності та атрибути

- **User (Користувач)**
  - `name` (string) — ім'я користувача.
  - `email` (string) — унікальна електронна пошта для ідентифікації.

- **Product (Товар)**
  - `title` (string) — назва товару.
  - `description` (string) — опис товару.

- **ProductVariant (Варіант товару)**
  - `size` (string) — розмір товару (наприклад, S, M, L).
  - `color` (string) — колір товару.
  - `price` (decimal) — ціна конкретного варіанту.
  - `stock` (int) — залишок на складі для цього варіанту.

- **Cart (Кошик)**
  - `session_id` (string) — ідентифікатор сесії або користувача, якому належить кошик.
  - `user_id` (string) — ідентифікатор зареєстрованого покупця (використовується для злиття кошиків при авторизації).

- **CartItem (Позиція в кошику)** — асоціативна сутність між `Cart` і `ProductVariant`.
  - `quantity` (int) — кількість одиниць певного варіанту товару в кошику.

- **Order (Замовлення)**
  - `status` (string) — поточний статус замовлення (наприклад, "створено", "оплачено", "відправлено").
  - `total_amount` (decimal) — загальна сума замовлення.

- **OrderItem (Позиція замовлення)** — асоціативна сутність між `Order` і `ProductVariant`.
  - `quantity` (int) — замовлена кількість.
  - `unit_price` (decimal) — зафіксована ціна за одиницю на момент оформлення замовлення.

- **Payment (Оплата)**
  - `payment_method` (string) — спосіб оплати (наприклад, карткою, готівкою при отриманні).
  - `payment_status` (string) — статус транзакції (успішно, неуспішно тощо).

- **Shipment (Доставка)**
  - `tracking_number` (string) — трекінг-номер поштового відправлення.
  - `delivery_status` (string) — статус доставки.
